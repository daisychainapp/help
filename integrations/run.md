# Run

_How to send Run form submissions to Daisychain_

[Run](https://www.designedtorun.com/) is an easy-to-use campaign website builder for Democrats and advocacy organizations.

Run makes it simple to send Run form submissions to Daisychain. To learn more about the configuring this integration, [click here.](https://help.designedtorun.com/en/articles/8437073-daisychain-integration)
