# Message Snippets

### Using Snippets

At the bottom of the message composition box view is the icon for Snippets, which looks like this:\
\
![](<../.gitbook/assets/image (13).png>)

When you click that icon, you'll be able to:

1. **Search snippets.** Just type in the box on top to search Snippets by name. \
   ​
2. **Select and insert an existing snippet.** Clicking a snippet will insert the templated message wherever your cursor is in the message box.

### Creating and Managing Snippets

Snippets can be managed in the "Snippet Library," which can be found by navigating to **Settings > Channels > Texting** and selecting the "Snippets" tab.&#x20;

Here, you'll be able to create, edit, and search for snippets in your account.

{% hint style="info" %}
Snippets are shared across all Users in your account.
{% endhint %}
