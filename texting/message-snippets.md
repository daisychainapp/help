# Message Snippets

At the bottom of the message composition box view is the icon for Snippets, which looks like this:\
\
![](<../.gitbook/assets/image (13).png>)

When you click that icon, you'll see options to either:&#x20;

1. **Add a new snippet**. When adding a new snippet, you enter a name for your snippet, a keyboard shortcut, and the actual content of the snippet itself.\
   ​
2. **Select and insert an existing snippet.** This will insert the templated message wherever your cursor is in the message box.\
   ​
3. **Delete a snippet.** Click the X next to any snippet to delete it.

{% hint style="info" %}
Snippets are shared across all Users in your account.
{% endhint %}
