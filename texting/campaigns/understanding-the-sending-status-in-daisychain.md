# Understanding the "Sending" Status in Daisychain

_In Daisychain, the delivery report provides a real-time update on the status of your message deliveries as they travel through the cellular network._

Once the message shows as "Sending", it means that it is no longer within Daisychain's processing and is en route to the recipient. This process can take some time, depending on network conditions and other factors.

Please note that there can be a waiting period of up to two hours for an affirmative delivery receipt or a delivery error report before the message status is updated.&#x20;
