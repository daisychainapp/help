# "Sending" Status

Once the message displays as "Sending", it means that it is no longer within Daisychain's processing and is en route to the recipient. This process can take some time, depending on network conditions and other factors.

Please note that there can be a waiting period of up to two hours for an affirmative delivery receipt or a delivery error report before the message status is updated.&#x20;

For every status a message can have, and how to see a single message's delivery history, see [Message Statuses](../message-statuses.md).
