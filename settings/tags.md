# Tags

To create a tag, navigate to Settings, and then Tags. Then click the + button to create a tag. You can create as many tags as you'd like.

<figure><img src="../.gitbook/assets/image (42).png" alt=""><figcaption></figcaption></figure>

Once your tag has been created, you can apply tags to people in In their Person record.\
You can remove tags from a Person by pressing the X on the applied tag.

<figure><img src="../.gitbook/assets/image (43).png" alt=""><figcaption></figcaption></figure>

&#x20;

{% hint style="info" %}
Currently, tags must be created before they can be used.
{% endhint %}

{% hint style="warning" %}
When you delete a tag, it will remove that tag from all People who have that tag.&#x20;
{% endhint %}
