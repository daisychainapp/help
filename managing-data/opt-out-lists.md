# Opt Out Lists

You can upload a list of phone numbers to be opted out from all your campaigns in Daisychain. To do this, create a spreadsheet with a "phone number" column and an "SMS Opt Out" column to upload. Make sure to set the value of "SMS Opt Out" to "TRUE" on each row. Your upload will look like this once you match the fields:\
\
